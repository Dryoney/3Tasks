#Rewiew_and_read_logs

Предназначена для обработки данных словаря и вычисления статистики по ним

##Описание

Этот проект предназначен для вычисления средних оценок каждого студента, студента с самой высокой средней оценкой, а также определения по какому предмету средняя оценка является наибольшей.

##Установка

1.Склонируйте репозиторий:
```bash
   git clone https://github.com/Dryoney/3Tasks.git
   ```
2. Перейдите в директорию проекта:
   ```bash
   cd 3Tasks
   ```

3. Установите необходимые зависимости, если они есть:
   ```bash
   pip install -r requirements.txt
   ```

## Использование

1. Изучите данные в заданном словаре и/или измените данные внутри него для изменения результатов.
2. Запустите программу:
   ```bash
   python main.py
   ```

## Формат словаря

Словарь должен содержать строки формата:
```
'Имя_студента': {'Назвение_предмета': оценка, 'название предмета': 90},
```
Количество имен и предметов может быть произвольным.


## Пример вывода

После запуска программы вы должны ввести имя студента, для которого вы хотите вычислить среднюю оценку. Далее на экран выведется студент с самой высокой средней оценкой.В конце определяется у какого предмета наибольшая средняя оценка.
